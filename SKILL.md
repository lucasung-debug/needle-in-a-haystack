# needle-in-a-haystack — Full-Cycle Research Skill

Obey `research.md` before producing, planning, executing, merging, or validating any research output.

1. Load `research.md` (the system directive). It runs the full cycle: **FRAME → DESIGN → ROUTE & COST → COLLECT → FALSIFY → SELF-CORRECT → REPORT.**
2. The reasoning root is `philosophy.md` (the Abduction Loop — Peirce). Load it when FRAME or FALSIFY needs the *why*.
3. For a research-plan / study-design request, load `methodology.md` (social-research design, 사회조사) during DESIGN.
4. Enforce the hard rules at every size: define the needle **and** the negative condition first; hold **≥2 candidates**; attach provenance to every claim; **try to falsify** before reporting; output **`NEEDLE NOT FOUND`** rather than fabricate; state confidence + what would change the answer.
5. Close every output with the compliance block in `research.md`. Mark outputs that skip framing, provenance, or falsification as INVALID and redo them.

Keep scaffolding minimal — load depth (`philosophy.md`, `methodology.md`) only when the phase needs it. If the scaffolding becomes the haystack, the needle gets missed.
